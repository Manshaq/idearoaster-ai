# IdeaRoaster AI

A simple web app that roasts your ideas before the market does.

## Features

- Paste your startup, hackathon, crypto, or app idea
- Get a funny roast, weak points analysis, better MVP direction, and a short pitch
- No login, database, or payment required
- Mobile responsive and dark-themed UI

## Setup

1. Clone the repo
2. Install dependencies: `npm install`
3. Start the app + API proxy: `npm run dev`

## Environment Variables

Create a `.env` file with your Franklin API credentials (or copy `.env.example`):

```
FRANKLIN_API_KEY=your_franklin_api_key
FRANKLIN_AGENT_ENDPOINT=your_franklin_agent_endpoint
```

## How it works

1. Paste your idea in the text area
2. Click "Roast My Idea"
3. Get a funny roast, analysis of weak points, better MVP version, and a short pitch
